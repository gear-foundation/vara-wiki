# Getting wVARA

## Hoodi

The Vara.eth faucet distributed Hoodi wVARA and ETH during the TestNet campaign. That campaign is complete and the faucet is no longer running — the WVARA contract itself is still deployed on Hoodi, see [Contract Addresses](/docs/vara-eth/reference/contract-addresses).

To experiment today, run a [full local stack](/docs/vara-eth/setup/local-node) — it deploys its own WVARA contract, so no faucet is needed.

## Mainnet

### Bridge from Vara Network

The primary way to get wVARA:

1. Acquire VARA on the Vara Network (exchanges, staking rewards, etc.) — see [Vara Network Tokenomics](/docs/vara-network/tokenomics)
2. Use the official [bridge](/docs/vara-network/bridge) to wrap VARA -> wVARA on Ethereum
3. wVARA is minted 1:1 against locked VARA

For the technical details of the bridge, see the [Bridge Technical Overview](/docs/vara-network/bridge/bridge_technical).

### Validator Rewards

Validators earn wVARA for:
- Executing programs and committing batches
- Participating in the FROST signing protocol
- Maintaining uptime and correct execution

See [Validators & Staking](/docs/vara-eth/economics/validators-staking) for details.
