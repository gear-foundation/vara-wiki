# Getting wVARA

## Hoodi

The Vara.eth faucet distributed Hoodi wVARA and ETH during the TestNet campaign. That campaign is complete and the faucet is no longer running — the WVARA contract itself is still deployed on Hoodi, see [Contract Addresses](/docs/vara-eth/reference/contract-addresses).

## Mainnet

### Verify the Token Before Acquiring It

Use the ERC-20 returned by the [Mainnet Router's `wrappedVara()` getter](https://etherscan.io/address/0x9C13FE9242dfe2ba2Cd446480A9308279aA74cb6#readProxyContract). The current [Vara Network bridge](/docs/vara-network/bridge/developer_hub#token-contracts) issues a different ERC-20 with the same ticker. Bridging VARA there does not fund a Vara.eth executable balance.

On Ethereum Mainnet, you can receive the Router's wVARA from an existing holder. There is no public faucet or documented public purchase or bridge route for this token. The current mainnet deployment does not distribute validator rewards on-chain.

## Local Development

Use [Gear's local Vara.eth network script](https://github.com/gear-tech/gear/blob/master/ethexe/scripts/start-local-network.sh) to develop without acquiring mainnet wVARA. The local network deploys its own token.

## Token Address

Use [Contract Addresses](/docs/vara-eth/reference/contract-addresses) to select the wVARA contract for your network. To add it to MetaMask, import that contract address as a custom ERC-20 token. See [Wallet Setup](/docs/vara-eth/setup/wallet-setup).
