# Networks

Vara.eth runs on Ethereum. The testnet is deployed on **Ethereum Hoodi**, and mainnet on **Ethereum Mainnet**.

<Callout type="note" title="Network Availability">
  Public Vara.eth endpoints (RPC and faucet) are currently offline between campaign phases. The parameters below are kept for reference — to experiment today, [run your own node](/docs/vara-eth/setup/local-node).
</Callout>

## Testnet (Ethereum Hoodi)

The Vara.eth testnet deployment on Ethereum Hoodi:

- Chain ID: `560048`
- Primary RPC: `https://hoodi-reth-rpc.gear-tech.io`
- Explorer: [hoodi.etherscan.io](https://hoodi.etherscan.io)

For the full endpoint matrix (HTTPS, WebSocket, health checks, and connection examples), use:

→ [Network Endpoints](/docs/vara-eth/reference/network-endpoints)

For Router and related contract addresses, use:

→ [Contract Addresses](/docs/vara-eth/reference/contract-addresses)

The Vara.eth mainnet deployment on Ethereum Mainnet:

- Explorer: [etherscan.io](https://etherscan.io)

For the full endpoint matrix (HTTPS, WebSocket, Beacon, Validator RPCs), use:

→ [Network Endpoints](/docs/vara-eth/reference/network-endpoints)
