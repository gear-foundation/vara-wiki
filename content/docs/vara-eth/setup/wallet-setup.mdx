# Wallet Setup

Vara.eth uses standard Ethereum wallets. If you have MetaMask, you're ready to go.

<Callout type="note" title="Endpoint Availability">
  The Vara.eth faucet and the Gear-operated RPC endpoints served the launch campaigns and are no longer running. Hoodi itself is unaffected: add the network with any public RPC, and get gas ETH from a public Hoodi faucet. For wVARA, run a [full local stack](/docs/vara-eth/setup/local-node), which deploys its own Router and WVARA contracts and lets you control the supply.
</Callout>

## Add Hoodi Network

The fastest way is to visit [Chainlist](https://chainlist.org/chain/560048) and click "Add to MetaMask."

**Manual setup:**

1. Open MetaMask → Settings → Networks → Add Network
2. Fill in the current Hoodi values from [Networks](/docs/vara-eth/setup/networks)
3. Save

## Get Test ETH

You need test ETH on Hoodi to pay for L1 transaction fees (sending messages to Mirror contracts, creating programs).

Get Hoodi ETH from any public Ethereum Hoodi faucet, such as [hoodifaucet.io](https://www.hoodifaucet.io/). The Vara.eth campaign faucet is no longer running, but it only ever distributed the same public Hoodi ETH.

<Callout type="note" title="Why ETH?">
  Even though Vara.eth uses the [reverse gas model](/docs/vara-eth/economics/reverse-gas-model) (programs pay for
  execution), you still need ETH for the base Ethereum transaction fee.
</Callout>

## Get Test wVARA

wVARA funds your program's [Executable Balance](/docs/vara-eth/interact/funding-executable-balance). Without wVARA, your program cannot execute messages.

The Vara.eth campaign faucet distributed Hoodi wVARA and is no longer running. On a [full local stack](/docs/vara-eth/setup/local-node), the WVARA contract is deployed together with your Router and you control the supply. On Ethereum Mainnet, wVARA is obtained by bridging VARA — see [Getting wVARA](/docs/vara-eth/economics/getting-wvara).

Once you have wVARA, fund your program via:

- `executableBalanceTopUp(value)` on the Mirror contract
- `ethexe` CLI
- TypeScript SDK

→ [wVARA Overview](/docs/vara-eth/economics/wvara-overview)

## Verify Your Setup

Quick checklist:

- MetaMask switched to Hoodi network
- ETH balance > 0
- wVARA balance > 0 (add token via [Contract Addresses](/docs/vara-eth/reference/contract-addresses))
- Your address visible on [Hoodi Etherscan](https://hoodi.etherscan.io)

## For CLI Users

If you prefer command-line workflows, insert your private key into `ethexe`:

```bash
ethexe key insert <YOUR_PRIVATE_KEY>
```

<Callout type="warning" title="Security">
  Only use test wallets with testnet keys. Never use your mainnet private key in development environments.
</Callout>
